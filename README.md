# Scientific Figures & Biological Data Cleaning Portfolio

Publication-grade scientific visualizations and reproducible Python (`pandas`, `matplotlib`, `seaborn`) data-cleaning scripts exported at 600 DPI (PNG) and vector PDF using colorblind-safe palettes.

## Included Deliverables
- Figure 1 — Multi-Group Boxplot: Treatment comparison overlaid with individual observations and statistical significance annotation (`Figure1_GeneExpression.png` / `.pdf`).
- Figure 2 — Differential Expression Volcano Plot: Fold-change vs. adjusted p-value plot highlighting upregulated/downregulated hits (`Figure2_VolcanoPlot.png` / `.pdf`).
- Figure 4 — Data Cleaning & QC Pipeline: Before-and-after comparison fixing date-corrupted gene symbols, inconsistent organism names, non-numeric tokens, and date formats (`Figure4_DataCleaning_BeforeAfter.png` / `.pdf`, `messy_bio_dataset_raw.csv`, `cleaned_bio_dataset_qc.csv`).
